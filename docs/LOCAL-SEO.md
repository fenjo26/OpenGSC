# Local SEO: локальные позиции, карточка бизнеса, NAP, каталоги, разметка, GBP

Дока закрывает две задачи волны «Ноябрь»: **N3 — локальные позиции в Rank Tracker** (запрос по
городу или координатам, отдельно — место в local pack) и **N4 — модуль Local** (карточка
бизнеса, проверка NAP на сайте и в каталогах, генератор LocalBusiness-разметки, интеграция с
Google Business Profile). Вход в модуль — пункт меню **Local**.

## Локальные позиции (N3)

Один и тот же запрос из США и из Салоник — разная выдача, а половина локальных кликов идёт из
тройки на карте (local pack). Rank Tracker считает их двумя разными числами:

- `position` — только органика;
- `localPack` (1–3) — место в паке.

Место в паке никогда не пишется в `position`: на нём держатся графики, `bestPosition` и алерт
`rank_drop`.

**Как пользоваться.** При добавлении ключа укажите «Город или координаты» (например
`Thessaloniki, Greece` или `40.5197,22.9709`; пусто — вся страна, как раньше). Город — часть
identity ключа: один запрос из Салоник и из Афин — две строки. Массово — строкой `ключ,город`.

**Провайдеры.** Провайдер должен уметь гео: Serper, DataForSEO или A-Parser; остальные дают
`location_unsupported` вместо тихой страновой подмены, нераспознанный город —
`location_unknown`. DataForSEO координаты шлёт как `location_coordinate`, название — как
`location_name`.

**Сверка с нами:** сначала домен (граница точки, `www.` игнорируется), затем название из
карточки бизнеса (Local, N4) + бренд-слова хоста: fold диакритик + Jaccard ≥ 0,6. У пак-места
сохраняется и название, которое показал Google (`localPackTitle`).

**В таблице и графике:** колонка Local pack — `#1–3` / «нет в паке» / «пака нет» / «—»
(провайдер не сообщает). В истории ключа вторая ось — ступенчатая линия места в паке, «×» =
проверен, но вне тройки. Уведомления об изменениях — раз в сутки, событие `local`.

Локальный ключ на A-Parser идёт обычным SE::Google-сканом (`SE::Google::Position` не принимает
гео).

## Карточка бизнеса, NAP, каталоги, разметка, GBP (N4)

Карточка (**Local → Business profile**) — источник правды для NAP, разметки и GBP: тип
schema.org, адрес по полям, телефон в E.164, часы по дням, координаты, sameAs, зоны
обслуживания. «Заполнить с сайта» разбирает JSON-LD/мета главной. Тип MassageTherapist в
schema.org отсутствует — выбирайте DaySpa/HealthAndBeautyBusiness.

**NAP-проверка (free):** главная + до 10 контакт-страниц + футер; телефоны сравниваются по
цифрам E.164, адрес — fold + Jaccard ≥ 0,7, название — без юр. форм.

**Каталоги:** вы вводите ссылки на свои карточки, OpenGSC сверяет их с профилем (еженедельно)
и подсказывает, где ещё разместиться (для GR: GBP, Facebook, Apple Business Connect, Bing
Places, xo.gr, vrisko.gr, 11888, TripAdvisor, Foursquare).

**Разметка:** генератор LocalBusiness JSON-LD с валидацией по требованиям Google, сравнением с
сайтом.

**GBP.** Доступ к Business Profile API — по заявке Google (до одобрения квота 0 — карточка
объясняет, красных ошибок нет). Подключение — отдельный OAuth scope `business.manage`; в
Google Cloud добавьте redirect URI (точный адрес показывает карточка). Отзывы — синк раз в
6 ч, ответ из UI; посты — черновик → расписание → публикация планировщиком; фото по публичному
URL.

**MCP:** `get_local_profile`, `check_nap`.
