# T5 — Интерфейс

**Ветка:** `feat/serpmon-t5` от `feat/serp-monitor`.
**Файлы:** `src/app/serp-monitor/**`, `src/components/serpmon/**`.

Работаешь только через API из `CONTRACT.md` §4 и типы из `src/lib/serpmon/types.ts`. Серверные
модули не импортировать. Все строки — `t("serpmon…")`, ключи уже есть (T0). Нужен ещё ключ —
используй и допиши в отчёт.

Образцы стиля и поведения: `src/app/drops/page.tsx` (фильтры, пагинация, пакетный цикл со
стопом через `useRef`, `notMigrated`), `src/app/aparser/page.tsx` + `isAparserConfigured()`
(проверка A-Parser — **не** только `localStorage`, см. `aparserConfigured.ts`), графики —
`recharts` как в дашборде, апдейты Google — `GET /api/gsc/algo-updates`.
Перед кодом прочитай гайд по App Router в `node_modules/next/dist/docs/` (параметры
динамических страниц в этой версии отличаются).

Референс внешнего вида — скриншот из поста (таблица «Запрос · Регион · Лидеры · Изменения»,
вкладки, кнопки справа сверху). Повторяем раскладку, но **чиним то, что там сломано**
(`CONTRACT.md` §0): одна плашка на домен, позиция в плашке, платформы скрыты.

## /serp-monitor — список проектов
- Карточки или таблица: название, `google · desktop · <страна>` (название страны из
  `lib/seo/regions.ts`, если там есть клиентский список, иначе код), запросов, последняя
  проверка (относительное время), следующая, мини-спарклайн `volatilitySeries`, бейдж
  «Шторм» если `lastRun.storm`, бейдж «На паузе».
- «Новый проект» — диалог (`components/serpmon/ProjectDialog.tsx`, он же для «Изменить»):
  название, страна (поиск по списку), язык (подставляется по стране), глубина
  (10/20/50/100), интервал (вручную/6ч/12ч/24ч/3дн/7дн), запросы (textarea + загрузка
  .csv/.txt в ту же textarea; живой счётчик строк), свои домены, скрытые хосты (с подсказкой
  про умолчания), хранение, уведомления. В режиме «Изменить» запросы не редактируются —
  отдельные кнопки «Добавить запросы» / «Заменить список».
- Пусто — `serpmonEmpty`. `notMigrated` — `serpmonNotMigrated`. A-Parser не настроен —
  `serpmonNoAparser` со ссылкой в настройки (создавать проект это не мешает).

## /serp-monitor/[id] — проект
**Шапка:** название, `google · desktop · Страна`, `serpmonCostNote` мелко. Кнопки:
«Изменить», «Фразы для Ahrefs» (скачать `export?kind=keywords`), «Пауза/Возобновить»,
**«Проверить сейчас»** (основная).
Запуск → `POST run`; `409 cooldown` → подтверждение `serpmonCooldown` → повтор с
`force: true`; `already_running` — просто показать прогресс. Прогресс — опрос
`GET runs?limit=1` раз в 3 с, пока `status === "running"`: полоса и `serpmonRunning`
(`done = ok + partial + failed`), по завершении — перезагрузить текущую вкладку. Опрос
остановить при уходе со страницы.

**Вкладка «Рынок»** (`components/serpmon/MarketTab.tsx`)
- Фильтры: запрос, домен, группа (из `ProjectDetail.groups`), «С изменениями», «Показать
  платформы». Счётчик `serpmonCountOf` (`total` из `all`). Фильтры — в URL-параметрах
  (`lib/urlParam.ts`), чтобы ссылку можно было переслать.
- Колонки: Запрос (+ группа мелко) · Лидеры (3 хоста) · Изменения · Волатильность
  (полоска 0–1 + число) · Ваша позиция.
- Плашки изменений (`components/serpmon/ChangeChip.tsx`):
  `enter` — зелёная `+host #to`; `exit` — красная `−host`, в title «выпал, был #from»;
  `up` — зелёная `↑ host from→to`; `down` — красная `↓ host from→to`; при `urls > 1` —
  `×N`. Скрытые (`hidden`) — не показывать, пока не включён «Показать платформы», тогда —
  приглушённые. Больше 12 плашек — «ещё N», раскрывается по клику. Клик по хосту в плашке
  ставит фильтр домена.
- Статус запроса `failed`/`partial` — иконка с текстом `serpmonProblem_<code>` в title,
  изменения не показываются (их нет), вместо них — `serpmonNoComparison` или причина.
- Пагинация (по 50), сортировка по волатильности/числу изменений/алфавиту.
- Клик по строке → боковая панель `KeywordDrawer.tsx`:
  - график позиций (`KeywordHistory.hosts`, ось Y перевёрнута, 1 сверху, `null` — разрыв),
    точки съёмов со статусом `failed` — отметки на оси X;
  - список съёмов (дата, статус, got/depth, волатильность, изменений);
  - сравнение: выбрать два съёма → `GET snapshots/[a]?compare=[b]` → две колонки 1…N,
    хосты, которые вошли/вышли, подсвечены; сверху — те же плашки из `diff`.

**Вкладка «Штормы»** (`StormsTab.tsx`)
- Если прогонов `done` с волатильностью меньше `STORM_MIN_BASELINE` — `serpmonStormsCalibrating`
  (с числами), график всё равно рисовать, если точки есть.
- График: линия `volatility` по прогонам, полоса фона (медиана ± 3 × 1.4826 × MAD по
  предыдущим 20 — посчитать на клиенте из тех же данных, функции из `volatility.ts` можно
  импортировать: модуль чистый), точки-штормы, вторая тонкая линия `volTop10`, области
  апдейтов Google (цвета `ALGO_UPDATE_COLORS`, диапазон `date…end`).
- Таблица прогонов: дата, триггер, ok/partial/failed, волатильность, `shareHigh`, сила
  шторма, бейдж; `error === "all_failed"` → `serpmonRunAllFailed`.
- Выбран прогон → «Сильнее всего трясло» (топ-10 запросов по волатильности этого прогона —
  возьми через `market?sort=volatility` для последнего прогона; для старых прогонов
  API нет — покажи только для последнего и напиши об этом в отчёте как кандидат на API).

**Вкладка «Домены»** (`DomainsTab.tsx`)
- Пресеты-кнопки: Все / Новые / Молодые / Растут / Падают / Отскочили; поле «Зарегистрирован
  не раньше, мес.» (активно для «Молодые»); поиск; «Показать платформы».
- Колонки: Домен (+ теги-бейджи) · Возраст (`ageMonths` → «N мес.»/«N г.», `ageError` →
  тусклое «—» с title `serpmonAgeUnknown`) · DR · Запросов (с `±Δ` от `prevKeywords`) ·
  Топ-10 · Лучшая · Средняя · Впервые.
- Кнопки «Загрузить возраст» и «Загрузить DR» с подписью `serpmonLoadFreeNote`: цикл
  `POST domains/enrich` пока `remaining > 0`, прогресс, «Стоп» (`useRef`). `keyFound: false`
  → явное сообщение, не «обновлено 0».
- «Выгрузить домены» — `export?kind=domains` с текущими фильтрами.
- Клик по домену → вкладка «Рынок» с фильтром по этому домену.

## Общие требования
- Мобильная ширина (~400px): таблицы в `overflow-x: auto`, шапка переносится, кнопки не
  вылезают (см. заметку про адаптивное меню — проблема уже ловилась).
- Тёмная тема — через существующие CSS-переменные, без хардкода цветов кроме зелёного/красного
  плашек (и те — через переменные, если они есть).
- Никаких `useEffect(() => setState(...))` на синхронных данных (`react-hooks/set-state-in-effect`).
- Состояние вкладки и фильтров — `usePersistedState` / URL, не глобальные переменные.
- Ошибка API — видимая строка над таблицей, не молчаливое пусто.
