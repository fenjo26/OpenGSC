## Часть A. Тональность
Трекер знает, **упомянут** ли бренд. Не знает, **как**: «надёжный перевозчик» и «много жалоб на
опоздания» сейчас выглядят одинаково.

- Анализ **только** ответов, где бренд упомянут или процитирован (`status ∈ {cited, mentioned}`).
- Один дешёвый LLM-вызов на ответ: провайдер и модель — из настроек SEO Tools (самая дешёвая
  доступная модель; как выбирается модель для судьи — посмотри в `judge.ts`, только чтение).
  Вход — фрагменты ответа вокруг упоминаний бренда (±2 предложения, ≤ 1500 символов), не
  весь ответ. Выход JSON: `{ sentiment: "positive|neutral|negative|mixed", score: -1..1,
  note: "≤ 300 символов на языке ответа" }`. Невалидный ответ → поле остаётся `null`.
- **Платно, поэтому по явному решению:**
  - кнопка «Оценить тональность» (по сайту, за выбранный период, с ценой до запуска —
    `N ответов × оценка токенов`), право `spend`;
  - переключатель в настройках AEO «Оценивать тональность новых ответов» — по умолчанию
    **выкл**. Когда включён, `aeoScheduler` оценивает новые ответы сразу после проверки.
- UI: у ответа — бейдж тональности с `note` во всплывающей подсказке; на «Доле голоса» —
  распределение тональности «вы / конкуренты» (для конкурентов тоже только по кнопке).
- Уже оценённые ответы не переоцениваются (поле не `null`).

## Часть B. Google AI Overviews
Движок `"ai_overview"` в `AeoEngine`. В отличие от ChatGPT и Perplexity, вопрос не
задаётся модели — берётся блок AI Overview из выдачи Google по этому вопросу.
- **DataForSEO** (если настроен ключ): SERP advanced, элемент `ai_overview` с `references`
  (url, domain, title) и текстом. → `citations`, `answerText`, `searched = true`.
- **A-Parser** (если настроен): строка ответа `SE::Google` содержит `ai_answer` / `ai_type`
  (проверено в истории SERP Monitor). Ссылок там может не быть — тогда только упоминание в
  тексте, `citations = []`, `status` по тексту.
- Нет ни того, ни другого → движок в списке недоступен с подсказкой, что нужно.
- Нет блока AI Overview в выдаче → отдельный статус `no_overview` (это не «не процитирован»:
  Google просто не показал обзор по этому вопросу). Добавь его в `AeoStatus` и учти в
  `sov.ts`: такие ответы не входят в знаменатель долей.
- Цена до запуска — как у остальных движков.

## Тесты
- Разбор `ai_overview` DataForSEO и строки A-Parser из фикстур.
- `no_overview` не попадает в знаменатель `buildSovReport`.
- Разбор ответа тональности: валидный, мусор → `null`, `score` вне диапазона → обрезка.
- Выбор фрагментов вокруг упоминаний (несколько упоминаний, лимит длины).
