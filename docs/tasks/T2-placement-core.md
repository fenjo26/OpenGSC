## Задача

опиши это в отчёте).

## Почему нельзя обойтись регуляркой

В репозитории уже есть `extractAuditHtml` (`src/lib/audit/pageSignals.ts`), которая
достаёт ссылки так:

```ts
for (const match of html.matchAll(/<a\s[^>]*href=["']([^"'#]+)["']/gi)) hrefs.push(decode(match[1]));
```

Для аудита этого хватает — там нужен только список URL. Здесь не хватает: нужны анкор,
`rel`, `alt` у картиночных, `<base href>` и корректное закрытие вложенных `<a>`.
Наивная регулярка склеит анкор соседней ссылки, и пользователь увидит чужой анкор
как свой. **Пиши свой токенизатор, `extractAuditHtml` не переиспользуй и не трогай.**

## Что именно должно работать

Эталон поведения — CLI `backlink-finder` (MIT, https://github.com/izzipizzy/backlink-finder).
Мы переносим его набор решённых крайних случаев в TypeScript. **Поставь в шапке файла
строку атрибуции** («derived from izzipizzy/backlink-finder, MIT») и добавь строку
в `CHANGELOG.md`… нет, `CHANGELOG.md` не твой файл — просто укажи это в отчёте.

### `canonicalizeDomain(input)`

Приводит к голому хосту любую форму записи и возвращает `null` для непригодного:

- `mysite.com`, `www.mysite.com`, `https://mysite.com/path`, `MySite.com.`,
  `mysite.com:443`, `HTTPS://MySite.COM/` → всё даёт `mysite.com`
- юникод и punycode взаимозаменяемы: `сайт.рф` и `xn--80aswg.xn--p1ai` дают
  одно и то же значение (используй `new URL()` — Node нормализует IDN сам)
- мусор отбрасывается сразу: `a..com`, `-bad.com`, `bad-.com`, пустая строка,
  `localhost`, голый IP, строка без точки → `null`

### `matchOwnedDomain(host, owned)`

- поддомены считаются своими: `blog.mysite.com` матчится на `mysite.com`
- **более конкретный выигрывает**: если настроены и `mysite.com`, и `shop.mysite.com`,
  то для `shop.mysite.com/x` вернуть `shop.mysite.com`
- совпадение только по границе метки: `notmysite.com` **не** матчится на `mysite.com`

### `parseRel(rel)`

Возвращает `RelFlags`. `nofollow`, `sponsored`, `ugc` — три независимых флага,
регистронезависимо, разделители — любые пробельные. `dofollow` истинен, только когда
не выставлен ни один из трёх. Булев «nofollow» сам по себе неверен: `rel="sponsored"`
веса не передаёт, но `nofollow` в нём нет.

### `decodeBody(buf, contentTypeHeader)`

Порядок определения кодировки: BOM (UTF-8/16/32) → `charset` из HTTP-заголовка →
`<meta charset>` или `<?xml encoding?>` в первых ~2 КБ → UTF-8 → CP1252.
Донорские площадки в русском сегменте регулярно отдают CP1251 без BOM — это не
экзотика, это типичный случай.

### `extractBaseHref(html, finalUrl)`

Первый `<base href>` из `<head>`, разрешённый относительно `finalUrl`. Нет — вернуть
`finalUrl`.

### `findPlacements(html, finalUrl, ownedDomains, opts)`

- относительные ссылки разрешаются от **фактически ответившей** страницы
  (`finalUrl`, то есть после редиректов), с учётом `<base href>`
- анкор: текст внутри `<a>`, теги вырезаны, HTML-сущности раскрыты, пробелы
  схлопнуты, обрезано до 200 символов
- ссылка-картинка: анкор берётся из `alt` у `<img>` внутри, `isImage = true`
- **вложенные `<a>` закрываются как в браузере**: открывающий `<a>` закрывает
  предыдущий незакрытый, текст не перетекает из ссылки в ссылку
- только `http`/`https`; `mailto:`, `tel:`, `javascript:`, `#anchor`, `data:` пропускаются
- дедупликация в пределах страницы по тройке (`linkUrl`, `anchor`, `rel.raw`);
  вторая ссылка на тот же URL с **другим** анкором остаётся отдельной строкой
- `sourceUrl` в результате — то, что передали в `opts.sourceUrl`, иначе `finalUrl`

## Тесты

`src/lib/seo/linkPlacement.test.ts`, на `node:test` + `tsx`, как остальные тесты
репозитория (посмотри `src/lib/audit/rules.test.ts` и `src/lib/security/safeFetch.test.ts`).
**Ни одного сетевого вызова** — все входные данные это строки HTML в самом тесте.

Минимум по одному тесту на каждый пункт выше, плюс обязательно:

- страница, где ссылка на наш домен есть, но она внутри `<img>` без `alt` → анкор пустой,
  строка всё равно возвращается
- страница с двумя ссылками на один URL, анкоры разные → две строки
- страница с двумя одинаковыми (URL + анкор + rel) → одна строка
- `<base href="https://cdn.example/">` + относительная ссылка `/page` → абсолютный URL
  строится от base, а не от finalUrl
- `rel="sponsored"` без `nofollow` → `dofollow: false`
- CP1251-страница с кириллическим анкором → анкор читается корректно
- `notmysite.com` при owned `mysite.com` → ноль совпадений
- вложенные `<a>`: `<a href=A>раз<a href=B>два</a>` → анкор первой «раз», второй «два»

Ориентир по объёму — 40+ кейсов; в оригинальном CLI их 44.

Допиши файл теста в конец строки `test:unit` в `package.json` — **только дописать
в конец, ничего не переставляя** (эту строку одновременно правит T4).

## Критерии приёмки

- `npm run test:unit` зелёный
- `npx tsc -p tsconfig.json --noEmit` без новых ошибок
- в файле нет ни `fetch`, ни импортов из `prisma`, ни `window`
- ни одна функция не делает предположений о том, что домен «наш» — список
  всегда приходит аргументом
