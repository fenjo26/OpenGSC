# Браузерное расширение OpenGSC (Chrome / Edge, MV3)

Расширение живёт в папке `extension/` репозитория и **не публикуется в Chrome Web Store** —
оно ставится как «распакованное». Это осознанное решение волны «Ноябрь» (N11): расширение
работает с вашим self-hosted инстансом, и магазину в этой схеме нечего подписывать и проверять.

Что умеет (v1.1, волна «Расширение» / wave-ext):

- **Боковая панель вместо попапа** — клик по иконке открывает side panel (Chrome ≥ 116), она
  не закрывается при переходах по сайту и сама обновляется при смене вкладки. Попап остался
  как запасной вариант для старых браузеров.
- **Разбор страницы** (вкладка «Страница», всё локально в браузере): Обзор (title/description
  с границами и полосами, canonical, robots, lang, viewport, слова, проблемы по группам и
  прозрачная оценка страницы), Заголовки (дерево H1–H6, скрытые и пропущенные уровни, клик —
  прокрутка к заголовку), Ссылки (внутренние/внешние/nofollow, области «в тексте/меню/подвал/
  вверху body», поиск и фильтры), Картинки (alt, размеры, формат, lazy, миниатюры), Schema
  (типы JSON-LD и microdata, кнопка Rich Results Test), Соцсети (превью Open Graph + все
  og:/twitter: теги), robots и sitemap (загрузка robots.txt, вердикт «закрыт ли URL для
  Googlebot», поиск URL в sitemap), Скорость (LCP/FCP/TTFB/CLS с порогами Google — лабораторные
  данные вашего браузера, не CrUX).
- **Подсветка проблем на странице** — рамки внутри одного shadow-host: картинки без alt,
  лишние H1, nofollow, внешние ссылки, ссылки без текста. Никаких классов и атрибутов на
  элементах страницы; выключается бесследно.
- **Экспорт** — CSV ссылок/картинок/заголовков и JSON всего разбора (BOM для Excel).
- **Слой OpenGSC для своих страниц** (вкладка «OpenGSC», читает ваш GSC): главный запрос за
  28 дней и совпадает ли он с title/H1, есть ли URL в sitemap, статус индекса, «подобрать
  мету» (бесплатно по коду; с ИИ — только после подтверждения), проверка футпринта title/
  description/H1 по всей сетке, позиции Rank Tracker, проблемы последнего аудита.
- **Режим донора для чужих страниц** (вкладка «Донор»): исходящие ссылки с rel и местом на
  странице, детектор восстановленного дропа/PBN (маркеры WayForge, остатки Wayback Machine,
  ссылка выше всего текста, generator инструмента восстановления), «эта страница уже
  ссылается на ваши сайты», DR/возраст/рефдомены хоста, «В Outreach» и «следить как дроп».
- **Оверлей выдачи Google** (включается в настройках, только на выбранных вами доменах
  Google): строка с данными OpenGSC под каждым результатом (DR, возраст, SERP Monitor,
  ссылается ли на вас, Outreach, дроп, PBN), шапка с вашими позициями по запросу из GSC и
  Rank Tracker, метриками запроса из кеша, кнопки «В Rank Tracker», «В SERP Monitor»,
  «Сохранить выдачу» (снимок попадает в SERP Monitor → «Снимки из браузера», в диффы и штормы
  он не входит — это персональная выдача с вашего IP) и «проверить клоакинг» (Googlebot и
  браузер, с Referer из выдачи).
- Всё из v1: «Отправить в OpenGSC» (очередь индексации / Outreach / ключ / CSV из таблицы),
  сводка по URL, быстрый аудит.

## Установка

1. **Соберите папку.** Расширение — это исходники в `extension/`, сборка не нужна. Чтобы
   получить архив (например, для второго компьютера):

   ```bash
   cd extension && zip -r ../opengsc-extension.zip .
   ```

2. **Установите.** Откройте `chrome://extensions` (Edge: `edge://extensions`) → включите
   **Режим разработчика** (Developer mode) → **Загрузить распакованное расширение** (Load
   unpacked) → выберите папку `extension/`. После каждого обновления кода — кнопка
   «Обновить» на карточке расширения.

3. **Токен.** OpenGSC → Настройки → **Браузерное расширение** → «Создать токен». Токен один
   на пользователя (`User.extToken`), отдельный от MCP-токена: отзыв расширения не трогает
   агентов, и наоборот. Перевыпуск мгновенно отзывает старый токен.

4. **Настройка расширения.** ПКМ по иконке → «Настройки» (options): URL инстанса
   (`https://opengsc.example.com`) и токен. «Сохранить» заодно запрашивает опциональное
   host-разрешение ровно на origin инстанса — можно отказать, тогда запросы идут через
   CORS-заголовки сервера. «Проверить связь» делает один бесплатный запрос и доказывает
   сразу URL, токен и белый список.

5. **ID расширения для CORS.** На странице настроек расширения скопируйте **ID расширения**
   (32 символа) и вставьте его в Настройки → Браузерное расширение → «Разрешённые ID
   расширения». Без этого сервер отвечает `403 origin_not_allowed`. ID стабилен, пока
   расширение стоит из той же папки; после переустановки из другой папки — новый ID.

6. **Права по желанию** (всё в тех же настройках):
   - «Анализировать любую страницу без клика по иконке» — разрешение «ко всем сайтам» для
     панели: без него разбор чужих страниц работает после клика по иконке (activeTab), с ним —
     автоматически при переключении вкладок. То же разрешение нужно вкладке robots, чтобы
     читать robots.txt/sitemap прямо из панели.
   - «Оверлей выдачи Google» — включите и отметьте нужные домены Google (по умолчанию
     предложены google.com и домен языка интерфейса). Разрешение запрашивается на кнопку
     «Сохранить» и только на отмеченные домены.

## Что расширение отправляет на сервер

Только то, что вы нажали, плюс токен в заголовке:

| Действие | Запрос | Что уходит |
|---|---|---|
| Открыть панель/попап | `GET /api/ext/page?url=` | URL текущей вкладки |
| Вкладка «OpenGSC» | `POST /api/ext/insights` | URL, title, description, первый H1 |
| «Подобрать мету» | `POST /api/ext/meta-fit` | то же + язык страницы (с ИИ — только после подтверждения, до 2 запросов к вашей модели) |
| Вкладка «Донор», оверлей | `POST /api/ext/hosts` | хосты (до 100) и, из оверлея, сам запрос + gl/hl |
| «Узнать возраст и DR» | `POST /api/ext/hosts/enrich` | хосты (до 20, RDAP/WHOIS и бесплатный DR) |
| «В очередь проверки индекса» | `POST /api/ext/index-queue` | URL текущей вкладки |
| «Сохранить как проспект» | `POST /api/ext/outreach` | URL (+ выделенный текст как заметка, если есть) |
| «Сохранить выдачу» | `POST /api/ext/serp/capture` | запрос, домен Google, gl/hl, позиции с URL/title/сниппетами |
| «В Rank Tracker» / «В SERP Monitor» / «Следить как дроп» | `POST /api/ext/serp/action` | запрос/хост и выбранный сайт/проект |
| «Проверить клоакинг» | `POST /api/ext/cloak` | URL, title и сниппет результата |

Разбор страницы, аудит, Core Web Vitals и донор-факты считаются в браузере и не покидают его.
HTML страниц, тексты абзацев и формы никуда не отправляются. Content-скрипты (панель на
чужой странице, оверлей) не ходят в сеть сами: запросы делает service worker расширения по
белому списку путей. История просмотров не отправляется: сводка тянется только пока панель
открыта.

## Безопасность на стороне сервера

- `/api/ext/**` открыт в `src/proxy.ts` без сессии, но каждый маршрут сам проверяет доступ:
  `Authorization: Bearer ogscext_…` → пользователь → его роль в workspace (как у MCP-токена:
  токен зрителя не может ставить URL в очередь — «act», тратить кредиты — «spend»).
- Сверка токена — постоянное время (sha256 + `timingSafeEqual`).
- CORS: `Access-Control-Allow-Origin` только для `chrome-extension://<id>` из
  `User.extAllowedIds`. Без совпадения origin — `403`. Никакого `*`.
- Rate limit: 60 запросов в минуту на токен (скользящее окно в памяти процесса), сверх — `429`
  с `Retry-After`; оверлей делает один запрос `hosts` на страницу выдачи, ответы кешируются
  на 10 минут. У «проверить клоакинг» свой лимит — 6 в минуту.
- Чтение — право `read`, бесплатные действия и сетевые проверки — `act`, запись (Rank
  Tracker, SERP Monitor, drops) — `write`, всё, что тратит деньги — `spend` и только с
  `confirm: true` от вас.

## Права расширения

- `activeTab` — доступ к вкладке только в момент клика по иконке или пункту меню.
- `contextMenus`, `storage`, `scripting` — меню, настройки в `chrome.storage.local`, инъекция
  скриптов разбора страницы.
- `sidePanel` — сама боковая панель (Chrome ≥ 116; в старых браузерах остаётся попап).
- `tabs` — панели нужно видеть URL активной вкладки при переключении (без него `tab.url`
  пустой). Содержимое вкладок этим правом не читается.
- `optional_host_permissions: http://*/*, https://*/*` — **шаблон**, из которого Chrome
  выделяет конкретные origin'ы по вашему клику: origin инстанса (при сохранении настроек),
  «все сайты» (для панели и robots) и отмеченные домены Google (для оверлея). В manifest нет
  ни `host_permissions`, ни `<all_urls>`: до явного разрешения расширение не может ходить ни
  на один сайт, кроме как через CORS-проверку сервера. Отозванное в `chrome://extensions`
  разрешение убирает домен из настроек оверлея при следующем запуске.

## Язык

`chrome.i18n`, `_locales/{en,ru}`. Язык следует интерфейсу браузера; остальные языки
приложения в расширении появятся позже.

## Ограничения (честно)

- Объём, CPC и конкуренцию «как у Keywords Everywhere» оверлей показывает только из кеша
  (`KeywordMetricCache`): запросов к Ahrefs расширение само не делает — это стоит юнитов.
- Оверлей читает только ту выдачу, которую вы сами открыли в браузере; своего SERP-скрейпера
  у расширения нет. Снимки из браузера — персональные: в диффы и штормы SERP Monitor они не
  попадают, их можно только сравнить с ближайшим автоматическим снимком вручную.
- DOM Google меняется: парсер выдачи (`lib/serpParse.js`) держит запасные селекторы и при
  неудаче молча не рисуется, страница не ломается. Другие расширения (Keywords Everywhere,
  MozBar) работают на той же выдаче — наши блоки их не трогают, их ссылки за органику не
  принимаются.
- CSV из контекстного меню: файл отдаётся через попап (откроется автоматически после клика
  по меню) — у service worker нет своего контекста для скачивания.
- Если у сайта выключена автопроверка индекса или URL нет в инвентаре sitemap, «в очередь»
  ответит причиной отказа — это честнее молчаливой видимости работы.
